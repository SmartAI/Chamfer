Start with text or reference images. Chamfer plans complex builds, retrieves the modeling knowledge it needs, executes build123d locally in your browser, and verifies geometry and visual fidelity before it finishes. Fine-tune dimensions with sliders, then export for printing or manufacturing. Prompts and attached images are sent to the model provider you configure; CAD execution, geometry, conversations, and settings stay local.

Plan, build, verify

For complex requests, Chamfer creates a persistent, evidence-backed plan before building. Successful CAD runs produce measured multi-view inspection evidence, and image-driven work must verify the current model against every active reference before finalizing.

Built for long-running CAD work

Plan-first execution

Evidence-backed plans keep long, multi-component builds aligned with the request.

Retrieval-backed docs

Client-side search retrieves focused build123d guidance when the agent needs it.

Progressive skills

Nine modeling and recovery skills load only when the current task calls for them.

Long-session memory

Domain-aware compaction preserves requirements, plans, and verification state.

Reference images

Paste or attach sketches and photos for retrieval and visual comparison throughout the run.

Kernel-enforced checks

Deterministic geometry checks prevent weakened verification from passing.

Export anything

Export STEP, STL, 3MF, or the raw build123d .py script.

Bring your own key

Use Anthropic, OpenAI, or Google while CAD execution stays local.
