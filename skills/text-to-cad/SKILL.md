name: text-to-cad
description: Plan text-to-CAD work as named components, measured dimensions, connectivity/intersection checks, validation, STEP export, and a concise final report with deliverable paths and measured evidence.
required_tools: read, write
---

Use the available tool list as the source of truth. If no CAD execution tool is
registered, create useful local scripts or plans and report that execution and
verification were unavailable.

When CAD tools are available, finish only after the model has been measured and
validated. The final report should list components, dimensions, volumes or
capacity when relevant, clearances, connectivity/intersection checks when
available, verification status, deliverable paths, and known limitations.
