# Design intent

Name the controlling dimensions and datums before choosing operations. Prefer a small set of meaningful parameters over repeated literals. Build the dominant form first, then additive and subtractive functional features, then patterns, and leave fillets and chamfers until stable topology exists.

Keep material, appearance, and geometry as separate requirements. For a revision, identify what the user intends to preserve and change the smallest durable feature or parameter that satisfies the request. Verify dimensions, feature presence, connectivity, and material or appearance through independent evidence rather than visual plausibility alone.
